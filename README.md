# CatNapClub_Digiphant

A Unity 6000.6.3f1 (URP) project in which our group drives a rigged elephant
through webcam motion tracking (MediaPipe → local UDP → Unity), built on the
DigiPhant student starter.

- **Scene:** `Assets/StudentWork/Scenes/CatNapClub_DigiPhant.unity`
- **Setup, data path, mappings, tests and restore steps:** [DIGIPHANT_SETUP.md](DIGIPHANT_SETUP.md)
- **Starter:** https://github.com/kommanderpi/studentstarter.git @ `5adcbea1f7b311b8bb15c17b3dc4742ae8fff3af`
